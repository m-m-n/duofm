# duofm - Unifies Orthodox File Manipulation

Go言語で書かれたターミナルベースの2画面ファイルマネージャです。クラシックなファイルマネージャにインスパイアされ、vimスタイルのキーバインドを採用しています。

## 機能

- **コアファイル管理**
  - 2画面インターフェース: 独立した設定で2つのディレクトリを並べて表示
  - vimスタイルキーバインド: hjkl + 矢印キーによるナビゲーション
  - ファイル操作: コピー、移動、削除、リネーム
  - ゴミ箱対応: freedesktop.org準拠のゴミ箱（復元、空にする、バッチ操作）
  - スマートリネーム: 拡張子保持リネーム(R)と全ファイル名リネーム(Shift+R)
  - パーミッション編集: Shift+Pでパーミッション変更（chmod）、再帰・バッチモード対応
  - ファイル作成: 新規ファイル(N)とディレクトリ(Shift+N)作成（カーソル位置管理付き）
  - 複数ファイルマーク: Spaceで複数選択してバッチ操作
  - シンボリックリンク対応: ターゲット表示、壊れたリンク検出、論理/物理パス移動
  - 上書き処理: スマート競合解決（上書き、スキップ、リネーム）
  - カーソル管理: 操作やナビゲーションでカーソル位置をスマートに保持
  - クリップボード操作: ファイル名とフルパスをクリップボードにコピー（OSC 52 + 外部ツール）

- **ナビゲーション・検索**
  - 検索・フィルタ: インクリメンタル検索(`/`)、正規表現検索(`Ctrl+F`)、SQLライククエリ(`Ctrl+G`)
  - 検索ダイアログ: シンタックスヒント、履歴ナビゲーション（上下キー）、インラインバリデーション
  - SQLライクフィルタ: WHERE句構文でサイズ、日付、種別クエリと複雑な式に対応
  - ディレクトリ履歴: ブラウザ風の前後移動（`Alt+←`/`Alt+→`または`[`/`]`）
  - パスジャンプ: `Ctrl+J`で任意のディレクトリへ直接移動（bash風Tab補完付き）
  - ページスクロール: Ctrl+D/UとPageUp/PageDownで大量ファイルを高速ナビゲート
  - 隠しファイル: `Ctrl+H`で表示切替（ペインごとの設定、`[H]`インジケータ付き）
  - クイックナビゲーション: ホーム(`~`)、前のディレクトリ(`-`)、ペイン同期(`=`)
  - ソート機能: 名前、サイズ、日付でソート（ドロップダウンメニュー、ライブプレビュー）
  - ブックマーク: よく使うディレクトリを保存してジャンプ（`B`/`Shift+B`）
  - スマートカーソル: 親ディレクトリに戻る際にカーソル位置を記憶
  - リフレッシュ: F5またはCtrl+Rでディレクトリ内容を再読み込み
  - 非同期読み込み: 適切なペイン識別でレスポンシブなUI

- **アーカイブ操作**（Linux専用）
  - アーカイブ作成: tar、tar.gz、tar.bz2、tar.xz、zip、7z（圧縮レベル選択可能）
  - アーカイブ展開: アーカイブ構造に適応したスマート展開
  - セキュリティチェック: Zip爆弾検出、ディスク容量検証、パストラバーサル防止
  - プログレス表示: リアルタイム進捗（ファイル数、経過時間、パーセンテージ）
  - コンテキストメニュー統合: 圧縮・展開がコンテキストメニューから利用可能
  - キャンセル可能: Escで適切なクリーンアップ付きキャンセル

- **表示・UI**
  - 3つの表示モード: Minimal、Basic（サイズ+日付）、Detail（パーミッション+所有者）
  - Unicode対応: 日本語、中国語、韓国語、絵文字の適切な表示（East Asian Width設定）
  - コンテキストメニュー: `@`でアクション選択（数字キーショートカット1-9）
  - デスクトップ環境検出: デスクトップ環境未検出時はOpen/Open withメニュー項目無効化
  - ヘルプシステム: スクロール可能なキーバインド一覧（256色パレット、16進数値付き）
  - ダイアログオーバーレイ: ダイアログ表示中も背景を暗くしてファイルリスト表示
  - Gitブランチ表示: Gitリポジトリ内ではステータスバーにアクティブブランチ表示
  - バージョン表示: ビルド時ldflagsからの動的バージョン表示（gitタグベース）

- **外部連携**
  - 外部ビューア: Enterキー動作設定可能（ページャ、xdg-open、カスタムアプリ、MIMEタイプベース）
  - MIMEタイプベース起動: ファイル種別ごとにアプリケーションをマッピング（ワイルドカード、コマンドフォールバック）
  - 外部エディタ: $EDITORでファイル編集（`E`キー、ファイルのディレクトリで開く）
  - シェルコマンド: `!`キーでカレントディレクトリでコマンド実行
  - シェル履歴: Ctrl+Rインクリメンタル検索（bash風の上下矢印ナビゲーション）
  - コマンド履歴永続化: セッション間で20,000コマンド保存（設定可能）
  - コンテキストメニュー: 「開く」「指定して開く」でカスタムアプリケーション起動
  - 作業ディレクトリ: 外部アプリはファイルのディレクトリで開く（カーソル位置保持）

- **カスタマイズ**
  - 設定ファイル: `~/.config/duofm/config.toml`（自動生成・自動マージ対応）
  - ホットリロード: 設定変更を自動検出して適用（fsnotify経由）
  - キーバインドカスタマイズ: 修飾キー対応（Ctrl、Shift、Alt）で全キー変更可能
  - カラーテーマ: 全UI要素の256色カスタマイズ（パレットリファレンス付き）
  - Enterキー動作: ページャ、xdg-open、カスタムアプリ、MIMEタイプベースから選択可能
  - ブックマーク: 設定ファイルに永続化（追加、編集、削除対応）
  - 自動マージ: 更新時に不足設定項目を自動追加

## インストール

### 必要条件

- Go 1.21以上

### ソースからビルド

```bash
# リポジトリをクローン
git clone https://github.com/sakura/duofm.git
cd duofm

# 依存関係をインストール
go mod download

# ビルド
make build

# 実行
./duofm
```

### システムへのインストール

```bash
# $GOPATH/binにインストール
make install

# どこからでも実行可能
duofm
```

## 使い方

### ナビゲーション

| キー | アクション |
|------|-----------|
| `j` / `↓` | カーソルを下に移動 |
| `k` / `↑` | カーソルを上に移動 |
| `h` / `←` | 左ペインに移動 / 親ディレクトリ |
| `l` / `→` | 右ペインに移動 / 親ディレクトリ |
| `Enter` | ディレクトリに入る / ファイルを開く |
| `~` | ホームディレクトリへ |
| `-` | 前のディレクトリへ |
| `=` | ペインを同期 |

### ファイル操作

| キー | アクション |
|------|-----------|
| `c` | 反対側のペインにコピー |
| `m` | 反対側のペインに移動 |
| `d` | 削除（確認あり） |
| `r` | リネーム |
| `n` | 新規ファイル作成 |
| `N` | 新規ディレクトリ作成 |
| `Space` | マーク/マーク解除 |

### 検索

| キー | アクション |
|------|-----------|
| `/` | インクリメンタル検索 |
| `Ctrl+F` | 正規表現検索 |

### 表示

| キー | アクション |
|------|-----------|
| `i` | 表示モード切替 |
| `Ctrl+H` | 隠しファイル表示切替 |
| `s` | ソート設定 |

### 外部連携

| キー | アクション |
|------|-----------|
| `v` | ビューアで開く |
| `e` | エディタで開く |
| `!` | シェルコマンド実行 |
| `@` | コンテキストメニュー |

### その他

| キー | アクション |
|------|-----------|
| `?` | ヘルプを表示 |
| `q` | 終了 |
| `F5` / `Ctrl+R` | 更新 |

## 設定

設定ファイルは `~/.config/duofm/config.toml` に配置します。

### キーバインド設定例

```toml
[keybindings]
move_down = ["J", "Down"]
move_up = ["K", "Up"]
copy = ["C"]
quit = ["Q"]
```

### カラー設定例

```toml
[colors]
cursor_bg = 39        # カーソル背景色（青）
directory_fg = 39     # ディレクトリ（青）
symlink_fg = 14       # シンボリックリンク（シアン）
```
