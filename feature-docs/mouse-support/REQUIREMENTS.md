# マウス操作サポート - 要件定義書

## 1. 概要

### 1.1 背景
UX の向上。

### 1.2 目的
ファイル一覧をマウスで操作できるようにする。

### 1.3 スコープ

対象:
- 左ボタンのクリックによるファイル選択（カーソル移動）
- 左ボタンのドラッグによる複数ファイルのマーク
- 左ボタンのダブルクリックによる Enter キーと同じ動作
- 画面座標からペイン・エントリへの対応付け（ヒットテスト）

対象外:
- ホイールによるスクロール
- 右ボタン・中ボタンの操作

## 2. ビジネス要件

### 2.1 ビジネス目標
- ユーザーがファイル一覧をマウスで操作できるようにする（UX の向上）。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| duofm のユーザー | ファイル一覧をマウスで操作するユーザー |

### 2.3 期待される効果
- UX の向上

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 関連要件 |
|----|----------------|----------|----------|
| UC01 | クリックでファイルを選択する | ユーザー | FR1, FR2 |
| UC02 | ドラッグで複数のファイルを選択する | ユーザー | FR1, FR4, FR5 |
| UC03 | ダブルクリックで Enter キーと同じ動作をする | ユーザー | FR6 |
| UC04 | ペインのエントリ以外の場所をクリックしてペインをアクティブにする | ユーザー | FR3 |

### 3.2 ユースケース詳細

#### UC01: クリックでファイルを選択する

**アクター**: ユーザー

**事前条件**:
- ダイアログ、ソートダイアログ、ミニバッファのいずれも開いていない
- bg 出力領域にフォーカスがない

**基本フロー**:
1. ユーザーがペインのエントリ行を左クリックする
2. そのペインのカーソルがクリックしたエントリへ移動する

**代替フロー**:
- 非アクティブなペインのエントリをクリックした場合、そのペインがアクティブになり、同じ操作でカーソルがクリックしたエントリへ移動する
- `..` をクリックした場合、カーソルは `..` へ移動する

**事後条件**:
- 既存のマークは変わらない

#### UC02: ドラッグで複数のファイルを選択する

**アクター**: ユーザー

**事前条件**:
- UC01 と同じ

**基本フロー**:
1. ユーザーがエントリ行で左ボタンを押す
2. ユーザーがポインタを別のエントリ行へ動かす
3. ドラッグ開始行から現在のポインタ行までのエントリが、ドラッグ開始時点のマークに追加してマークされる
4. ユーザーが左ボタンを離す
5. カーソルは離した行のエントリにある

**代替フロー**:
- 非アクティブなペインで押した場合、そのペインが先にアクティブになる
- ポインタを戻して範囲を縮めた場合、このドラッグで追加したマークだけが外れる。ドラッグ開始時点のマークは外れない
- ポインタが最初の可視エントリ行より上、または最後の可視エントリ行より下にある場合、範囲は最初／最後の可視エントリで止まる
- ポインタがもう一方のペイン、タイトルバー、ステータスバーの上にある場合も、範囲はドラッグを開始したペインの中に留まる
- 同じ行で押して離し、別の行へ動かさなかった場合はクリック（UC01）になる

**事後条件**:
- `..` はマークされない
- ドラッグ中に一覧はスクロールしない（scrollOffset は変わらない）

#### UC03: ダブルクリックで Enter キーと同じ動作をする

**アクター**: ユーザー

**事前条件**:
- UC01 と同じ

**基本フロー**:
1. ユーザーがエントリを左ボタンで押す（クリックとして動作する）
2. ユーザーが 500 ms 以内に同じエントリ（同じペイン・同じディレクトリ・同じエントリ名）を再び左ボタンで押す
3. そのエントリに対して Enter キーと同じ動作を行う
    - ファイル: EnterBehavior に従って開く
    - ディレクトリ: そのディレクトリに入る
    - `..`: 親ディレクトリへ移動する

**代替フロー**:
- 2 回目の押下が 500 ms を超えた場合、または別のエントリだった場合は、Enter の動作を行わない
- 非アクティブなペインのエントリをダブルクリックした場合、1 回目の押下でそのペインがアクティブになる
- ダブルクリックが成立した後の次の押下は、新しいクリック列の始まりになる（素早い 3 回目の押下で Enter は再度実行されない）

**事後条件**:
- Enter キーを押した場合と同じ状態になる

#### UC04: ペインのエントリ以外の場所をクリックしてペインをアクティブにする

**アクター**: ユーザー

**事前条件**:
- UC01 と同じ

**基本フロー**:
1. ユーザーがペイン内のエントリ以外の場所（ヘッダ行、最後のエントリより下の空行など）を左クリックする
2. そのペインがアクティブになる

**代替フロー**:
- タイトルバー、ステータスバー、どちらのペインにも属さない列をクリックした場合は何も起きない

**事後条件**:
- そのペインのカーソルとマークは変わらない

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 |
|----|--------|------|
| FR1 | ヒットテスト | マウスイベントの画面座標を、描画と同じレイアウト値で対象（ペイン・エントリ）に対応付ける |
| FR2 | クリックでファイルを選択 | エントリ行の左クリックで、そのペインのカーソルをクリックしたエントリへ移動する |
| FR3 | エントリ以外の場所のクリック | ペイン内のエントリ以外の場所の左クリックで、そのペインをアクティブにする |
| FR4 | ドラッグで複数ファイルを選択 | 左ボタンのドラッグで、開始行から現在行までのエントリをマークする |
| FR5 | ドラッグ範囲の制限 | ドラッグ範囲は開始したペインの可視エントリ内に留め、一覧はスクロールしない |
| FR6 | ダブルクリックで Enter と同じ動作 | 500 ms 以内の同じエントリへの 2 回目の押下で Enter キーと同じ動作を行う |
| FR7 | モーダル状態ではマウスを無視 | ダイアログ等が開いている間はマウス入力を無視する |
| FR8 | 対象外のマウス入力 | ホイール、右ボタン、中ボタンを無視する |

### 4.2 機能詳細

#### FR1: ヒットテスト

**説明**: マウスイベントの画面座標を、描画と同じレイアウト値を使って対象に対応付ける。

**入力**:
- X, Y: 整数 - マウスイベントの画面座標（0 始まり）
- width, height: 整数 - 画面の幅と高さ
- scrollOffset: 整数 - ペインのスクロール位置
- 可視行数: 整数 - ペインの getVisibleLines の値（bg 出力の分割表示を反映済み）
- エントリ数: 整数 - ペインのエントリ数

**出力**:
- 対象: どのペインにも属さない / ペインの非エントリ領域 / ペインのエントリ（エントリの index）

**ビジネスルール**:
- 行 0 はタイトルバー、最終行（height-1）はステータスバー。その間の行がペインに属する
- ペイン幅は width/2。X が [0, width/2) なら左ペイン、[width/2, 2*(width/2)) なら右ペイン。幅が奇数のときに残る右端の列はどちらのペインにも属さない
- ペイン内の最初の 3 行（パスヘッダ、情報ヘッダ、枠線）は非エントリ行。エントリ行は画面の行 4 から始まる
- エントリの index は scrollOffset + (Y - 4)。(Y - 4) が可視行数未満で、かつ index がエントリ数未満のときだけ有効
- それ以外のペイン内の行（最後のエントリより下の空行、`(No matches)` の行、bg 出力の区切り行と出力行）は、そのペインの非エントリ領域

#### FR2: クリックでファイルを選択

**説明**: エントリ行の左クリックで、そのペインのカーソルをクリックしたエントリへ移動する。

**ビジネスルール**:
- 既存のマークは変えない
- クリックしたペインが非アクティブなら、そのペインをアクティブにし、同じ操作でカーソルをクリックしたエントリへ移動する
- `..` をクリックするとカーソルは `..` へ移動する

#### FR3: エントリ以外の場所のクリック

**説明**: ペイン内の非エントリ領域の左クリックで、そのペインをアクティブにする。

**ビジネスルール**:
- そのペインのカーソルとマークは変えない
- タイトルバー、ステータスバー、両ペインの外の列のクリックは無視する

#### FR4: ドラッグで複数ファイルを選択

**説明**: エントリ行で左ボタンを押し、ポインタを別のエントリ行へ動かすと、そのペイン（開始ペイン）でドラッグが始まる。

**ビジネスルール**:
- 開始ペインが非アクティブなら、先にアクティブにする
- ドラッグ中は、ドラッグ開始行から現在のポインタ行までのエントリを、ドラッグ開始時点のマークに追加してマークする
- 範囲はポインタに合わせてその場で変わる。範囲を縮めると、このドラッグで追加したマークは外れるが、ドラッグ開始時点のマークは外れない
- `..` はマークしない
- カーソルはポインタ行に追従し、離した行で止まる
- 同じ行で押して離し、別の行へ動かさなかった場合はクリック（FR2）であり、ドラッグではない

#### FR5: ドラッグ範囲の制限

**説明**: ドラッグ範囲を開始ペインの可視エントリ内に制限する。

**ビジネスルール**:
- ドラッグ中はポインタの行だけを使う。ポインタがもう一方のペイン、タイトルバー、ステータスバーの上にあっても、範囲は開始ペインの中に留まる
- ポインタが最初の可視エントリ行より上、または最後の可視エントリ行より下（エントリの少ないディレクトリで最後のエントリより下の空行を含む）にあるとき、範囲は最初／最後の可視エントリで止まる
- ドラッグ中に一覧はスクロールしない（scrollOffset は変わらない）

#### FR6: ダブルクリックで Enter と同じ動作

**説明**: 同じエントリ（同じペイン・同じディレクトリ・同じエントリ名）に対する左ボタンの押下が、前回の押下から 500 ms 以内に来たとき、そのエントリに対して Enter キーと同じ動作を行う。

**ビジネスルール**:
- ファイルは EnterBehavior に従って開く。ディレクトリはその中に入る。`..` は親ディレクトリへ移動する
- 1 回目の押下はクリック（FR2）として動作する。非アクティブなペインのアクティブ化も含む
- ダブルクリックが成立した後の次の押下は、新しいクリック列の始まりになる（素早い 3 回目の押下で Enter は再度実行されない）

#### FR7: モーダル状態ではマウスを無視

**説明**: 次の状態の間は、すべてのマウス入力を無視する。

**ビジネスルール**:
- ダイアログが開いている（m.dialog != nil）
- ソートダイアログがアクティブ
- ミニバッファがアクティブ（検索モード、シェルコマンドモード）
- bg 出力領域にフォーカスがある
- bg 出力の分割表示でファイル一覧にフォーカスがある場合、ファイル一覧部分のクリックとドラッグは FR1〜FR6 のとおり動作し、区切り行・出力部分のクリックは無視する

#### FR8: 対象外のマウス入力

**説明**: 左ボタン以外のマウス入力を無視する。

**ビジネスルール**:
- ホイールイベントは無視する（ホイールスクロールは対象外）
- 右ボタン、中ボタンのイベントは無視する

### 5.4 保守性要件
- NFR2（ui パッケージへの配置）: マウス処理は internal/ui に置き、internal/fs のロジックと分ける。ヒットテストはレイアウト状態（width、height、ペイン幅、scrollOffset、可視行数、エントリ数）だけで決まる純粋な関数とし、端末なしでユニットテストできるようにする
- NFR3（レイアウト値の一元化）: ヒットテストは描画と同じレイアウト値（width/2 のペイン幅、タイトル行、3 行のペインヘッダ、bgSplitHeights を含む getVisibleLines）を使い、行とエントリの対応が描画とずれないようにする
- NFR4（ダブルクリック判定の時刻のテスト容易性）: 500 ms のダブルクリック判定に使う時刻の取得元を差し替え可能にし、ユニットテストで判定時間の内外の押下を決定的に再現できるようにする

### 5.5 互換性要件
- NFR1（キーボード操作の非退行）: 既存のキーボード操作の挙動は変わらず、既存のユニットテストと E2E テストはすべて変更なしで通る
- NFR5（既存のマウスモード）: cmd/duofm/main.go の既存のプログラムオプション tea.WithMouseCellMotion() をマウス報告モードとして使い続ける。端末モードを追加しない

## 11. 成功基準

### 11.1 受け入れ基準
- [ ] AC1: ファイルをクリックするとカーソルがそのファイルへ移動する（マークは変わらない）。非アクティブなペインのファイルをクリックすると、そのペインがアクティブになり、カーソルがそのファイルへ移動する（FR1, FR2）
- [ ] AC2: エントリをまたいでドラッグすると、開始行から離した行までのすべてのエントリ（`..` を除く）が既存のマークに追加してマークされ、カーソルは離した行にある。範囲は可視行内に制限され、一覧はスクロールしない（FR1, FR4, FR5）
- [ ] AC3: エントリを 500 ms 以内にダブルクリックすると、そのエントリで Enter キーを押したのと同じ動作になる（FR6）
- [ ] AC4: ペインの空行やヘッダをクリックすると、そのペインがアクティブになるだけである。タイトルバーとステータスバーのクリックでは何も起きない（FR3）
- [ ] AC5: ダイアログ、ソートダイアログ、ミニバッファ、フォーカス中の bg 出力が表示されている間は、マウス入力で何も変わらない。ホイール、右ボタン、中ボタンの入力でも何も変わらない（FR7, FR8）
- [ ] AC6: 既存のユニットテストと E2E テストがすべて変更なしで通る（NFR1）

## 13. 用語定義

| 用語 | 定義 |
|------|------|
| ヒットテスト | マウスイベントの画面座標を、ペインとエントリに対応付ける処理 |
| エントリ行 | ペイン内でエントリが表示される行。画面の行 4 から始まり、可視行数とエントリ数の範囲内にある行 |
| 非エントリ領域 | ペイン内のエントリ行以外の行（ヘッダ 3 行、最後のエントリより下の空行、`(No matches)` の行、bg 出力の区切り行と出力行） |
| 開始ペイン | ドラッグを開始したペイン |
| クリック列 | ダブルクリック判定の対象となる一連の押下。ダブルクリック成立後の次の押下で新しく始まる |
| 可視行数 | ペインの getVisibleLines の値。bg 出力の分割表示を反映済み |
| bg 出力の分割表示 | バックグラウンドのシェルコマンドの出力を、ファイル一覧と分割して表示する状態 |
| ミニバッファ | 検索モードやシェルコマンドモードの入力欄 |

- [x] A2 ドラッグ時のマーク: 開始行から現在行までの範囲を既存のマークに追加してマークする。範囲はポインタにその場で追従し、カーソルは離した行で止まる
