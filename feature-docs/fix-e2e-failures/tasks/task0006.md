## Design

### Observed failure (verify round 1)
- Full run and archive-only run: the 4 failing assertions are all in `test_multifile_compress` ("8. Compress 3 files" not shown, format dialog not shown, archive not created, archive contents).
- The test sends `m` to mark files. In the current app `m` is the move key (KeyMove), and marking is Space (KeyMark in `internal/ui/keys.go`). `test/e2e/scripts/tests/mark_tests.sh` marks with the tmux key name `Space`.
- After the wrong key, the move flow starts and `multi1.txt` ends up open in the editor.

### Change
- Replace every key press in `test_multifile_compress` that is meant to mark a file with the same Space key the mark tests send.
- Each of the three source files is reached by name (search filter, as in the rest of the file) before it is marked. The test does not depend on the cursor moving to the next row after a mark.
- Everything else in the test stays as task0002 left it: `@`, the "8. Compress 3 files" assertion, tar.gz by number, destination pane rule, archive existence and member checks, cleanup.

## Acceptance Criteria (MANDATORY)

- [ ] AC-1: `test_multifile_compress` sends no `m` key. Each of its three source files is marked with the key name `Space`, the same key name `test/e2e/scripts/tests/mark_tests.sh` uses to mark.
- [ ] AC-2: Before each Space press, the cursor is placed on that file by its name (search filter). The test has no step that relies on the cursor advancing after a mark.
- [ ] AC-3: `KeyMark` in `internal/ui/keys.go` at the base commit is the space character, and `KeyMove` is `m`. The task's test record lists both with their source file.
- [ ] AC-4: The test still asserts the numbered line "8. Compress 3 files" before pressing `8`, still selects tar.gz by number after asserting its numbered line, and keeps its existence, member, and cleanup checks unchanged in meaning.
- [ ] AC-5: No function other than `test_multifile_compress` changes. No file outside `test/e2e/scripts/tests/archive_tests.sh` changes (no Go source, `helpers.sh`, runner, Dockerfile or Makefile change). The 9 archive `test_` function names are unchanged and no new `test_`-prefixed function exists.
- [ ] AC-6: The bash syntax check on `test/e2e/scripts/tests/archive_tests.sh` passes. If shellcheck is installed, the changed lines add no findings.
