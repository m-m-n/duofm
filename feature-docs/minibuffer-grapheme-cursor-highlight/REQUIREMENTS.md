# minibuffer-grapheme-cursor-highlight - 要件定義書

## 1. 概要

### 1.1 背景
ミニバッファのカーソルが書記素（ZWJ 連結の絵文字など）の途中の rune にあるとき、カーソル位置の rune だけを反転表示するため、結合文字列が分かれて描画される。結合が分かれると描画幅も増え、収まっていた入力が縮小ループで切り詰められることがある。

### 1.2 目的
- ミニバッファのカーソルが書記素（ZWJ 連結の絵文字など）の途中にあっても、結合文字列を分けて描画しない
- 結合の分割で描画幅が増え、収まっていた入力が縮小ループで切り詰められることをなくす

### 1.3 スコープ
- 対象: ミニバッファのカーソル移動（Left / Ctrl+B / Right / Ctrl+F）と、View のカーソル位置の反転表示（スクロール経路を含む）
- 対象外: 文字挿入・スペース挿入・Backspace・Delete・Ctrl+K・Ctrl+U の編集操作、Ctrl+A・Ctrl+E・SetInput・SetCursorPos・CursorPos の動作（いずれも既存の rune 単位のまま）

## 2. ビジネス要件

### 2.1 ビジネス目標
- ミニバッファのカーソルが書記素（ZWJ 連結の絵文字など）の途中にあっても、結合文字列を分けて描画しない
- 結合の分割で描画幅が増え、収まっていた入力が縮小ループで切り詰められることをなくす

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| ミニバッファの利用者 | ミニバッファに結合文字列を含む入力を行い、カーソルを移動する |

### 2.3 期待される効果
- 家族絵文字などの書記素の上では、Left/Right 1 回で書記素 1 つを越える
- カーソルが書記素の途中にあっても、結合文字列が分かれずに描画される
- 収まる入力が切り詰められずに表示される

### 3.2 ユースケース詳細

#### UC01: 結合文字列を含む入力の上でカーソルを移動する

**アクター**: ミニバッファの利用者

**事前条件**:
- ミニバッファが開いている

**基本フロー**:
1. 家族の絵文字（U+1F468 U+200D U+1F469 U+200D U+1F467 U+200D U+1F466）を入力する
2. カーソルを左へ 1 つずつ動かす
3. カーソルは書記素単位で移動し、カーソルを含む書記素全体が 1 つの反転範囲として描画される

**代替フロー**:
- SetCursorPos（タブ補完の NewCursorPos）でカーソルが書記素の途中に置かれた場合も、書記素全体を 1 つの反転範囲として描画する

**事後条件**:
- どの段階でも、家族絵文字が分かれずに表示される

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 状態 |
|----|--------|------|------|
| FR1 | 書記素単位のカーソル移動 | Left/Ctrl+B・Right/Ctrl+F で書記素単位に移動する | 確定 |
| FR2 | カーソルを含む書記素全体の反転表示 | カーソル位置の rune を含む書記素全体を 1 つの反転範囲で描画する | 確定 |

### 4.2 機能詳細

#### FR1: 書記素単位のカーソル移動

**説明**: Left と Ctrl+B は、カーソルを直前の書記素の開始位置へ移動する。カーソルが書記素の途中にある場合は、その書記素の開始位置へ移動する。Right と Ctrl+F は、カーソルを含む書記素の終了位置（次の書記素の開始位置）へ移動する。先頭での Left/Ctrl+B と末尾での Right/Ctrl+F はカーソルを動かさない。cursorPos は rune 位置のまま保持する。

**ビジネスルール**:
- 入力先頭の孤立した幅 0 の rune（先頭の結合文字や ZWJ）は、それ自体を 1 つの書記素として移動する
- 空入力、カーソルが先頭・末尾の場合も上記に従う

#### FR2: カーソルを含む書記素全体の反転表示

**説明**: カーソルが末尾以外にあるとき、View はカーソル位置の rune を含む書記素全体 [開始, 終了) を 1 つの反転範囲として描画する。SetCursorPos などで書記素の途中に置かれた場合も同じ。カーソルが末尾にあるときの末尾のブロックカーソルは変えない。

**ビジネスルール**:
- 入力先頭の孤立した幅 0 の rune（先頭の結合文字や ZWJ）は、それ自体を 1 つの書記素として反転する
- 書記素の途中での文字挿入の後にカーソルが書記素の途中になっても、反転は書記素全体とする

#### FR3: 収まる入力の非切り詰め

**説明**: prompt と入力全体（反転表示を含み、カーソルが末尾なら末尾のブロックカーソルを含む）の実際の表示幅が内容幅に収まる場合、カーソルが書記素の途中にあっても入力を切り詰めずに表示する。

#### FR4: スクロール時のカーソルの書記素

**説明**: 入力が収まらずスクロールする経路では、カーソルを含む書記素を常に丸ごと扱う。カーソルの書記素全体の幅が残り幅を超える場合は入力を描画しない（既存のステップ3と同じ扱い）。カーソル前後の区切り位置はカーソルを含む書記素の開始位置と終了位置とする。カーソルから離れた側の表示窓の端は、既存の width unit 単位の切り方のまま変えない。

**ビジネスルール**:
- スクロール経路（ステップ4/5）では、カーソルの書記素の開始・終了を前後の区切りに使う
- カーソルの書記素全体の幅が残り幅を超える場合（ステップ3）は入力を描画しない

#### FR5: 編集操作は変えない

**説明**: 文字挿入・スペース挿入・Backspace・Delete・Ctrl+K・Ctrl+U は rune 単位の既存の動作のまま変えない。Ctrl+A・Ctrl+E・SetInput・SetCursorPos・CursorPos の動作（rune 位置）も変えない。

**ビジネスルール**:
- 書記素の途中での文字挿入・Backspace・Delete・Ctrl+K・Ctrl+U は rune 単位のまま

- A5: 文字挿入・Backspace・Delete・Ctrl+K・Ctrl+U は rune 単位のまま変えない。
- A6: 「再発を検出するテスト」は internal/ui/minibuffer_test.go の単体テストで満たし、E2E テストは追加しない。
- A7: 反転の見た目（lipgloss の Reverse）と、末尾のブロックカーソル（反転した空白 1 桁）は変えない。
