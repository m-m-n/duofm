# クリップボードコピー - 要件定義書

## 1. 概要

### 1.1 背景
ファイル名やファイルパスをクリップボードにコピーする手段がない。

### 1.2 目的
カーソル位置のファイル名またはフルパスをクリップボードにコピーする機能を追加する。

### 1.3 スコープ
- コンテキストメニューに「ファイル名をコピー」と「パスをコピー」の項目を追加する
- クリップボードへの書き込みはOSC 52を優先し、外部コマンドをフォールバックとする
- 対象は単一ファイル（カーソル位置のファイル）のみ

## 2. ユースケース

### 2.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | ファイル名をコピー | ユーザー | 高 |
| UC02 | フルパスをコピー | ユーザー | 高 |

### 2.2 ユースケース詳細

#### UC01: ファイル名をコピー

**アクター**: ユーザー

**事前条件**:
- ペインにファイルまたはディレクトリが表示されている
- カーソルがファイル/ディレクトリ上にある

**基本フロー**:
1. ユーザーがコンテキストメニューを開く
2. 「Copy file name」を選択する
3. カーソル位置のファイル名がクリップボードにコピーされる
4. ステータスバーに完了メッセージが表示される

**事後条件**:
- クリップボードにファイル名が格納されている

#### UC02: フルパスをコピー

**アクター**: ユーザー

**事前条件**:
- ペインにファイルまたはディレクトリが表示されている
- カーソルがファイル/ディレクトリ上にある

**基本フロー**:
1. ユーザーがコンテキストメニューを開く
2. 「Copy full path」を選択する
3. カーソル位置のファイルのフルパスがクリップボードにコピーされる
4. ステータスバーに完了メッセージが表示される

**事後条件**:
- クリップボードにフルパスが格納されている

## 3. 機能要件

### 3.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | ファイル名コピー | カーソル位置のファイル名をクリップボードにコピー | 高 |
| F02 | フルパスコピー | カーソル位置のファイルのフルパスをクリップボードにコピー | 高 |
| F03 | OSC 52クリップボード書き込み | OSC 52エスケープシーケンスでクリップボードに書き込む | 高 |
| F04 | 外部コマンドフォールバック | OSC 52が使えない場合に外部コマンドでクリップボードに書き込む | 高 |
| F05 | コンテキストメニュー項目追加 | コンテキストメニューに2項目を追加 | 高 |
| F06 | ステータスバー通知 | コピー成功/失敗時にステータスバーにメッセージを表示 | 高 |

### 3.2 機能詳細

#### F01: ファイル名コピー

**説明**: カーソル位置のファイル名（ディレクトリ名含む）をクリップボードにコピーする。

**入力**:
- カーソル位置のファイルエントリ

**出力**:
- ファイル名文字列がクリップボードに格納される

#### F02: フルパスコピー

**説明**: カーソル位置のファイルの絶対パスをクリップボードにコピーする。

**入力**:
- カーソル位置のファイルエントリ
- 現在のディレクトリパス

**出力**:
- フルパス文字列がクリップボードに格納される

#### F03: OSC 52クリップボード書き込み

**説明**: OSC 52エスケープシーケンスを使用してクリップボードに書き込む。

#### F04: 外部コマンドフォールバック

**説明**: OSC 52が使えない環境では、外部コマンド（xclip, xsel, wl-copy等）を使用してクリップボードに書き込む。

**検出順序**:
1. `wl-copy` (Wayland)
2. `xclip` (X11)
3. `xsel` (X11)

#### F05: コンテキストメニュー項目追加

**説明**: コンテキストメニューに以下の項目を追加する。

| 項目名 | アクションID |
|--------|-------------|
| Copy file name | copy_name |
| Copy full path | copy_path |

- マークされたファイルが存在する場合（複数選択時）はコンテキストメニュー自体が複数ファイル向けになるため、これらの項目はマーク数0のときのみ有効とする

#### F06: ステータスバー通知

**説明**: コピー操作の結果をステータスバーに表示する。

| 状態 | メッセージ |
|------|-----------|
| 成功（ファイル名） | `Copied: {ファイル名}` |
| 成功（フルパス） | `Copied: {フルパス}` |
| 失敗 | `Copy failed: {エラー内容}` |

- メッセージは3秒後に自動消去

### 3.3 親ディレクトリ（..）の扱い

- `..`エントリ上ではコピー項目を無効（disabled）にする

## 4. 非機能要件

### 4.1 パフォーマンス要件
- クリップボードへのコピー操作: 100ms以内

### 4.2 互換性要件
- Linux環境で動作すること
- OSC 52対応ターミナルではOSC 52で動作すること
- OSC 52非対応環境では外部コマンドで動作すること

## 5. テストシナリオ

- [ ] 正常系: ファイル名がクリップボードにコピーされる
- [ ] 正常系: フルパスがクリップボードにコピーされる
- [ ] 正常系: コピー成功時にステータスバーにメッセージが表示される
- [ ] 正常系: ステータスバーメッセージが3秒後に消える
- [ ] 異常系: 親ディレクトリ（..）ではコピー項目が無効
- [ ] 異常系: クリップボードツールが存在しない場合のエラーハンドリング
- [ ] コンテキストメニューに項目が正しく表示される
- [ ] マークファイルがある場合はコピー項目が無効
