# 要件定義書: シェルコマンド機能拡張

## 概要

duofmのシェルコマンド実行機能に対して、TAB補完とシェルログ確認機能を追加し、「Press Enter to continue...」の待機動作を改善する。

## 要件一覧

### REQ-1: TAB補完

シェルコマンドモード（`!`キー）でTABキーによるコマンド補完を実装する。

- **REQ-1.1:** TABキーでファイルパス補完を行う（アクティブペインのカレントディレクトリを基準）
- **REQ-1.2:** コマンド先頭位置ではPATH上の実行可能コマンド名を補完する
- **REQ-1.3:** 候補が1つの場合は自動補完する
- **REQ-1.4:** 候補が複数の場合は共通プレフィックスまで補完する（zshデフォルト動作）
- **REQ-1.5:** ディレクトリ補完時は末尾に `/` を付加する

### REQ-2: シェルコマンド終了後の即座復帰

「Press Enter to continue...」を廃止し、コマンド出力を短時間表示してから自動復帰する。

- **REQ-2.1:** シェルコマンド完了後、2秒間出力を表示してからTUIに自動復帰する
- **REQ-2.2:** コマンドの標準出力と標準エラー出力をキャプチャし、ログとして保持する
- **REQ-2.3:** 2秒の待機時間は固定値とする

### REQ-3: シェルログ確認機能

セッション中に実行した全シェルコマンドのログを確認するキーバインドを追加する。

- **REQ-3.1:** 設定可能なキーバインドでシェルログを表示する（デフォルト: Ctrl+L）
- **REQ-3.2:** セッション中（duofm起動中）に実行した全コマンドのログを保持する
- **REQ-3.3:** ログは $PAGER（デフォルト: less）でフルスクリーン表示する
- **REQ-3.4:** ログには各コマンドの実行コマンド、実行ディレクトリ、出力（stdout + stderr）を含む
- **REQ-3.5:** アクション名は `shell_log` とし、keybindingsで設定可能にする

### REQ-4: ログファイル管理

- **REQ-4.1:** ログファイルのパスは `<dir>/duofm-shell-<PID>.log`（PIDはduofmのプロセスID）
- **REQ-4.2:** デフォルトのログディレクトリは `/tmp`
- **REQ-4.3:** ログディレクトリは config.toml の `shell_log_dir` で設定可能
- **REQ-4.4:** プログラムの明示的終了時にログファイルを削除する
- **REQ-4.5:** プログラムが異常終了した場合、ログファイルが残存することを許容する

## ユーザーの要求原文

- TAB補完: zshにあるような機能を実装し、長いコマンドもTABで補完できるようにする
- シェルコマンド終了後、Press Enter to continue...を出さずに戻る
- その代わりにシェルのログを確認するキーバインドを用意する
