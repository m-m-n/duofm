# デスクトップ環境なしでOpen/Open withメニューを無効化 - 要件定義書

## 1. 概要

### 1.1 背景
duofmはSSH接続やヘッドレスサーバーなど、デスクトップ環境がないマシンでも使用される。そのような環境では`xdg-open`や`xdg-mime`が動作しないため、「Open」「Open with ...」メニューは機能しない。

### 1.2 目的
デスクトップ環境がない場合に「Open」「Open with ...」メニューをグレーアウト表示し、ユーザーが選択できないようにする。

### 1.3 スコープ
- コンテキストメニューの「Open」「Open with ...」項目の無効化表示
- デスクトップ環境の有無を環境変数で検出

## 2. ビジネス要件

### 2.1 ビジネス目標
ヘッドレス環境でのユーザー体験を改善し、使用不可能な機能が明確に分かるようにする。

### 2.2 対象ユーザー
| ユーザータイプ | 説明 |
|----------------|------|
| SSHユーザー | リモートサーバーにSSH接続してduofmを使用するユーザー |
| サーバー管理者 | デスクトップ環境のないサーバーでファイル管理を行うユーザー |

### 2.3 期待される効果
- 動作しない機能をユーザーが誤って選択することを防止
- UIの状態から環境の制約が明確に理解できる

## 3. ユースケース

### 3.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | デスクトップ環境なしでコンテキストメニュー表示 | ユーザー | 高 |
| UC02 | デスクトップ環境ありでコンテキストメニュー表示 | ユーザー | 高 |

### 3.2 ユースケース詳細

#### UC01: デスクトップ環境なしでコンテキストメニュー表示

**アクター**: SSHユーザー / サーバー管理者

**事前条件**:
- DISPLAY環境変数が未設定
- WAYLAND_DISPLAY環境変数が未設定

**基本フロー**:
1. ユーザーがファイルを選択
2. ユーザーがコンテキストメニューを開く
3. 「Open」「Open with ...」がグレーアウト表示される
4. ユーザーがこれらの項目を選択しようとしても選択できない

**事後条件**:
- メニューは表示されるが、該当項目は選択不可

#### UC02: デスクトップ環境ありでコンテキストメニュー表示

**アクター**: デスクトップユーザー

**事前条件**:
- DISPLAYまたはWAYLAND_DISPLAY環境変数が設定されている

**基本フロー**:
1. ユーザーがファイルを選択
2. ユーザーがコンテキストメニューを開く
3. 「Open」「Open with ...」が通常表示される
4. ユーザーが項目を選択可能

**事後条件**:
- 従来通りの動作

## 4. 機能要件

### 4.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | デスクトップ環境検出 | 環境変数でデスクトップ環境の有無を判定 | 高 |
| F02 | メニュー項目無効化 | Open/Open withメニューをグレーアウト表示 | 高 |

### 4.2 機能詳細

#### F01: デスクトップ環境検出

**説明**: 環境変数を確認してデスクトップ環境の有無を判定する

**判定ロジック**:
- `DISPLAY`環境変数が設定されている → デスクトップ環境あり（X11）
- `WAYLAND_DISPLAY`環境変数が設定されている → デスクトップ環境あり（Wayland）
- どちらも未設定 → デスクトップ環境なし

**出力**:
- bool: デスクトップ環境の有無

#### F02: メニュー項目無効化

**説明**: デスクトップ環境がない場合、「Open」「Open with ...」をグレーアウト表示する

**対象ファイル**:
- `context_menu_dialog.go`: コンテキストメニューの「Open」「Open with ...」項目

**表示方式**:
- グレーアウト表示（薄い色で表示）
- 選択不可（キーボード操作でスキップ）

## 5. 非機能要件

### 5.1 パフォーマンス要件
- 環境変数の確認は起動時に1回のみ実行し、結果をキャッシュする

### 5.2 保守性要件
- デスクトップ環境検出ロジックは独立した関数として実装し、再利用可能にする

## 6. UI/UX要件

### 6.1 グレーアウト表示
- メニュー項目のテキストを薄い色（灰色）で表示
- カーソル移動時にスキップされる

### 6.2 視認性
- グレーアウト項目と通常項目の区別が明確であること

## 7. テストシナリオ

### 7.1 テスト観点
- [ ] 正常系: DISPLAY設定時にOpen/Open withが有効
- [ ] 正常系: WAYLAND_DISPLAY設定時にOpen/Open withが有効
- [ ] 正常系: 両方未設定時にOpen/Open withが無効
- [ ] 境界値: 空文字が設定されている場合の動作

## 8. 確認事項

### 8.1 確認済み事項

- [x] デスクトップ環境の検出方法: 環境変数確認（DISPLAY/WAYLAND_DISPLAYが設定されているかで判定）
- [x] 非表示方式: 無効化表示（グレーアウトして表示するが選択不可にする）

### 8.2 未確認・保留事項
