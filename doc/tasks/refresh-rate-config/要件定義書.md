# リフレッシュレート設定 - 要件定義書

## 1. 概要

### 1.1 背景
ディレクトリ一覧の自動更新機能がなく、外部プロセスによるファイル変更を検知するには手動リフレッシュ（F5/Ctrl+R）が必要。

### 1.2 目的
ディレクトリ一覧とディスク容量を定期的に自動更新する機能を追加し、そのリフレッシュ間隔を設定ファイルで制御可能にする。

### 1.3 スコープ
- ディレクトリ一覧とディスク容量の定期的な自動更新機能を追加する
- リフレッシュ間隔（秒）を `config.toml` で設定可能にする
- デフォルトは3秒
- 0を指定すると自動更新を無効化できる
- 既存のディスク容量監視（5秒固定）を廃止し、`refresh_rate` に統合する

## 2. ユースケース

### 2.1 ユースケース一覧
| ID | ユースケース名 | アクター | 優先度 |
|----|----------------|----------|--------|
| UC01 | ディレクトリ自動更新 | ユーザー | 高 |
| UC02 | リフレッシュレート変更 | ユーザー | 高 |
| UC03 | 自動更新の無効化 | ユーザー | 中 |

### 2.2 ユースケース詳細

#### UC01: ディレクトリ自動更新

**アクター**: ユーザー

**事前条件**:
- duofmが起動している
- `refresh_rate` が1以上に設定されている

**基本フロー**:
1. duofmが設定されたリフレッシュ間隔ごとにディレクトリ一覧を再読み込みする
2. ファイルの追加・削除・変更が反映される
3. カーソル位置は可能な限り維持される

**事後条件**:
- ペインの内容が最新のディレクトリ状態を反映している

#### UC02: リフレッシュレート変更

**アクター**: ユーザー

**事前条件**:
- `config.toml` が存在する

**基本フロー**:
1. ユーザーが `config.toml` の `refresh_rate` を変更する
2. 設定ホットリロードにより新しいリフレッシュレートが即座に適用される

**事後条件**:
- 新しい間隔で自動更新が動作する

#### UC03: 自動更新の無効化

**アクター**: ユーザー

**事前条件**:
- `config.toml` が存在する

**基本フロー**:
1. ユーザーが `config.toml` の `refresh_rate` を `0` に設定する
2. 設定ホットリロードにより自動更新が停止する

**事後条件**:
- 自動更新が無効になり、手動リフレッシュ（F5/Ctrl+R）のみでディレクトリ一覧が更新される

## 3. 機能要件

### 3.1 機能一覧
| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F01 | 定期自動更新 | 設定された間隔で両ペインのディレクトリ一覧とディスク容量を再読み込み | 高 |
| F02 | リフレッシュレート設定 | `config.toml` で `refresh_rate` パラメータを設定可能にする | 高 |
| F03 | バリデーション | 設定値の範囲チェック（0〜60秒） | 高 |
| F04 | ホットリロード対応 | 設定変更時にリフレッシュレートを即座に反映 | 高 |

### 3.2 機能詳細

#### F01: 定期自動更新

**説明**: 設定されたリフレッシュ間隔で両ペインのディレクトリ一覧とディスク容量を自動的に再読み込みする。

**動作仕様**:
- リフレッシュ間隔ごとに `autoRefreshMsg` を発行する
- 両ペインのディレクトリ一覧を再読み込みする
- 両ペインのディスク容量を更新する（`syscall.Statfs` によるメタデータ読み取りのみでI/O負荷なし）
- カーソル位置は現在選択中のファイル名に基づいて維持する
- ダイアログ表示中はリフレッシュを実行しない（ダイアログ操作との競合を避けるため）
- 既存の `diskSpaceTickCmd`（5秒固定）を廃止し、この仕組みに統合する

#### F02: リフレッシュレート設定

**説明**: `config.toml` に `refresh_rate` パラメータを追加する。

**設定形式**:
```toml
refresh_rate = 3
```

**パラメータ仕様**:
- キー名: `refresh_rate`
- 型: 整数（秒）
- デフォルト値: 3
- 有効範囲: 0〜60
- 0: 自動更新を無効化

#### F03: バリデーション

**説明**: `refresh_rate` の値が有効範囲外の場合、デフォルト値を使用し警告を出す。

| 入力値 | 動作 |
|--------|------|
| 0 | 自動更新を無効化 |
| 1〜60 | 指定された秒数で自動更新 |
| 負の値 | デフォルト値（3秒）を使用し、警告を出す |
| 61以上 | デフォルト値（3秒）を使用し、警告を出す |

#### F04: ホットリロード対応

**説明**: 設定ファイルの変更時にリフレッシュレートを即座に反映する。

**動作仕様**:
- 既存の設定ホットリロード機構（`ConfigFileChangedMsg`）で `refresh_rate` の変更を検知する
- 新しいリフレッシュレートでタイマーを再設定する

## 4. 非機能要件

### 4.1 パフォーマンス要件
- ディレクトリ再読み込みは既存の `refresh` 操作と同等のパフォーマンス
- ディスク容量取得は `syscall.Statfs`（カーネルメタデータ読み取り）のみでI/O負荷なし

### 4.2 互換性要件
- 既存の `config.toml` に `refresh_rate` が未設定の場合、デフォルト値（3秒）で動作する
- 設定自動マージにより、既存の設定ファイルに `refresh_rate` が自動追加される

## 5. テストシナリオ

- [ ] 正常系: デフォルト値（3秒）で自動更新が動作する
- [ ] 正常系: `refresh_rate = 5` で5秒間隔の自動更新が動作する
- [ ] 正常系: `refresh_rate = 0` で自動更新が無効になる
- [ ] 正常系: 設定ホットリロードでリフレッシュレートが即座に反映される
- [ ] 異常系: 負の値を指定した場合、デフォルト値が使用され警告が出る
- [ ] 異常系: 61以上の値を指定した場合、デフォルト値が使用され警告が出る
- [ ] ダイアログ表示中は自動更新が実行されない
- [ ] カーソル位置が自動更新後も維持される
